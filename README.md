# Описание керна

Офлайн-приложение геолога для документации керна скважин. Данные хранятся на телефоне, интернет не нужен. Реализованы разделы ТЗ 45–60.

## Что умеет

**Ввод данных**
- Проекты и скважины: устье (восток / север / отметка), азимут, угол, глубины, станок. Координаты можно взять с GPS телефона.
- Описание керна по интервалам: порода, структура, текстура, окисление, изменения с интенсивностью, минералы с содержанием, прожилкование, комментарий. Всё хранится по полям (п.45). Кнопка «Как предыдущий» копирует описание соседнего интервала. Перекрытия интервалов не допускаются.
- Пробы с автонумерацией (`KOSM26DD-014-012`). Нарезка проб по интервалу с учётом литологических контактов. Контрольные пробы: стандарты, бланки, дубликаты.
- Фото керна с камеры. Снимки сжимаются до 2400 пикселей и привязываются к ящику и интервалу.
- Инклинометрия. Траектория считается методом минимальной кривизны.
- Справочники редактируются: породы с цветом и штриховкой, изменения, минералы, элементы. Новый химический элемент — это просто строка в справочнике (п.46).

**Лабораторные данные**
- Импорт анализов из Excel (.xlsx) и CSV (п.48). Колонки сопоставляются автоматически, пользователь подтверждает.
- Перед загрузкой каждая строка проверяется: скважина, Sample_ID, совпадение интервала, дубли, нечисловые значения.
- Итог импорта — по каждой строке с причиной. Загрузку можно отменить.

**Анализ и визуализация**
- Геологическая колонка с графиками содержаний (п.49, 53). Нажатие на интервал открывает карточку с описанием, анализами и фото (п.50).
- Фильтры по содержаниям с условиями «И / ИЛИ» и пересчётом единиц (п.51).
- Рудные интервалы по бортовому содержанию со средневзвешенным содержанием (п.52).
- Сопоставление скважин (п.54) и 2D-разрез (п.55).

**Выгрузка и сохранность**
- Выгрузка в Excel (листы на русском) и в CSV с заголовками HOLEID / FROM / TO для программ моделирования.
- Резервная копия всей базы с фото в один .zip и восстановление из неё.

## Установка на Android

Адрес веб-версии: **https://kassymkhanov1987-ops.github.io/kern-logging/**

1. Откройте адрес в Chrome на телефоне.
2. Меню Chrome → «Установить приложение».
3. Приложение появится на главном экране и будет работать без интернета.

Или APK-файл: **https://github.com/kassymkhanov1987-ops/kern-logging/releases/download/apk/kern-logging.apk** — скачать на телефон и открыть (Android попросит разрешить установку из этого источника). Новая версия ставится поверх старой, данные сохраняются.

Данные хранятся только на телефоне. Регулярно делайте резервную копию: Настройки → «Создать копию».

## Структура

```
www/                    исходный код (без сторонних библиотек)
  index.html, sw.js     страница и офлайн-кэш
  js/store.js           локальная база (IndexedDB): проект → скважина → интервал → проба → анализ → фото
  js/model.js, calc.js  запросы, средневзвешенные интервалы, фильтры, контроль данных
  js/geo.js             траектория скважины, проекция на разрез
  js/importer.js        импорт лабораторных файлов
  js/exporter.js        Excel / CSV / резервная копия
  js/sheets.js, zip.js  чтение и запись .xlsx и .zip
  js/views/*            экраны
build.py                сборка www → dist (сжатие, версия офлайн-кэша)
capacitor.config.json   настройки APK
.github/workflows/      автосборка: веб-версия на GitHub Pages + APK
```

## Сборка

- **Веб-версия:** `python3 build.py`. Папку `dist/` можно разместить на любом статическом хостинге (GitHub Pages, Netlify, Vercel); нужен только HTTPS.
- **APK:** при каждом изменении в ветке `main` workflow `.github/workflows/build.yml` публикует веб-версию, собирает APK и выкладывает его в релиз `apk` (ссылка выше).
- **Подпись APK:** ключ лежит в `android-keys/debug.keystore`, чтобы обновления ставились поверх старой версии без потери данных. Репозиторий публичный, поэтому перед выдачей приложения геологам ключ стоит перенести в секреты GitHub (Settings → Secrets) и убрать из репозитория.

## Ограничения

- Старый формат Excel `.xls` не читается. Сохраняйте лабораторные файлы как `.xlsx` или CSV.
- Данные одного телефона не синхронизируются с другими. Обмен — через выгрузку и резервные копии.
